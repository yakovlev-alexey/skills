## Goal
Agree on exactly five strategic priorities for the next quarter, each with a named owner and first measurable step — without implying or committing to budget increases.

## Key outcomes
- Shared picture of current reality, strategic purpose, and non‑negotiable constraints (including flat budget)
- Draft strategic themes narrowed to a ranked shortlist, then to five priorities with explicit trade‑offs and deprioritized items
- Five priorities validated through premortem and consent; each with an owner, success signal, and first 15% action within existing authority
- Published artifact set and follow‑up cadence so commitments survive after the lab

## Per-block detail

### Block: Opening frame (09:00–09:20, Day 1)

**Why:** Align 25 stakeholders on why they are here, what "done" looks like, and what facilitators will not allow (budget promises, back-channel deals).

**Format:** [ToP Focused Conversation](https://www.top-network.org/use-focused-conversation)

**Board / frame (ASCII):**
```
┌──────────────────────────────────────────────────────────────┐
│  DECISION QUESTION                                           │
│  "Which 5 priorities will we commit to this quarter,         │
│   each with an owner — within current budget?"               │
├──────────────────────────────────────────────────────────────┤
│  CONSTRAINT CHARTER (visible all day)                        │
│  ✓ Reprioritize, stop, reshape within existing resources     │
│  ✗ No new budget commitments from this room                  │
│  ✓ Escalation paths for org-dependent items → parking lot    │
├──────────────────────────────────────────────────────────────┤
│  ORIENT │ REFLECT │ INTERPRET │ DECIDE (today = Orient only) │
└──────────────────────────────────────────────────────────────┘
```

**Facilitator instruction:** Calm, neutral tone. Name political sensitivity explicitly: "Disagreement is expected; we are choosing focus, not winners." Read constraint charter aloud; ask for thumb consent (not applause). Do not let executives pre‑announce priorities before exploration. Redirect budget debates to Day 2 Circles & Soup.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 5 min | Welcome; co‑fac roles; hybrid parity rules (board = truth) |
| 2 | 5 min | Read decision question + constraint charter; thumbs check |
| 3 | 5 min | ORIENT: "What data/context did you bring?" — 3–4 lightning inputs (room + online) |
| 4 | 5 min | REFLECT: "What is at stake personally/organizationally?" — round-robin, 30 sec each, online first |

**Block output:** Decision question and constraint charter pinned on digital board Frame zone; parking lot column opened.

### Block: Safety baseline (09:20–09:35, Day 1)

**Why:** High political sensitivity requires knowing whether honest dissent is possible before hopes/fears and prioritization.

**Format:** [Safety Check](https://www.funretrospectives.com/safety-check/)

**Board / frame (ASCII):**
```
┌─────────────────────────────────────┐
│  Safety (1–5, anonymous on board)   │
│  [|||||||||||||||||||||||||||||]    │
│  Avg: ___   If <3.5 → adjust depth  │
└─────────────────────────────────────┘
```

**Facilitator instruction:** Use anonymous board voting (not show of hands). If average < 3.5, add [Heard, Seen, Respected](https://www.liberatingstructures.com/heard-seen-respected) (10 min) and shorten World Cafe rounds. Never press individuals to explain low scores.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 3 min | Explain scale; silent anonymous score on board |
| 2 | 2 min | Reveal aggregate only; state adjustment plan if low |
| 3 | 10 min | (Conditional) HSR if score low — otherwise proceed |

**Block output:** Safety score recorded; facilitation depth note on board.

### Block: Arrive and surface stakes (09:35–10:15, Day 1)

**Why:** Help participants arrive as people; surface optimism and anxiety before strategic debate.

**Format:** [Check-in](https://toolbox.hyperisland.com/check-in-questions) + [Hopes and Fears](https://www.teamretro.com/retro-template/hopes-and-fears-retrospective/)

**Board / frame (ASCII):**
```
┌──────────────────┬──────────────────┐
│     HOPES        │     FEARS        │
│  (sticky each)   │  (sticky each)   │
├──────────────────┴──────────────────┤
│  CHECK-IN: "What needs to be true   │
│  for this quarter to feel worth it?"│
└─────────────────────────────────────┘
```

**Facilitator instruction:** Check-in prompt: "Name one hope for this quarter in one sentence." Then silent brainwriting for Hopes/Fears (2 min each column). Cluster quickly; do not debate. Flag budget-related fears to parking lot tagged `#budget`.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 10 min | Round-robin check-in (online speakers first); scribe captures themes |
| 2 | 5 min | Silent Hopes stickies |
| 3 | 5 min | Silent Fears stickies |
| 4 | 15 min | Pair share → plenary themes; quick affinity by facilitator |

**Block output:** Hopes/Fears clusters on board; check-in themes in margin.

### Block: Shared context (10:30–11:45, Day 1)

**Why:** Establish a common factual base before purpose and exploration; reduce talking past each other.

**Format:** [What, So What, Now What](https://www.liberatingstructures.com/what-so-what-now-what)

**Board / frame (ASCII):**
```
┌─────────────┬─────────────┬─────────────┐
│    WHAT     │   SO WHAT   │  NOW WHAT   │
│  (facts)    │  (meaning)  │ (questions) │
├─────────────┼─────────────┼─────────────┤
│             │             │             │
└─────────────┴─────────────┴─────────────┘
```

**Facilitator instruction:** WHAT = pre-read metrics + live corrections only (no strategy yet). SO WHAT = implications, no solutions. NOW WHAT = questions for World Cafe, not decisions. Cut solutioning firmly.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 15 min | WHAT: pre-read summary + 5 min corrections/additions (board) |
| 2 | 20 min | SO WHAT: table groups (mixed room/online) → 1 insight each |
| 3 | 15 min | NOW WHAT: collect open questions; vote top 6 for World Cafe |
| 4 | 15 min | Plenary: confirm shared picture; facilitator reads back |

**Block output:** Three columns filled; top 6 World Cafe questions selected.

### Block: Strategic purpose (12:00–13:00, Day 1)

**Why:** Anchor prioritization in purpose so political factions don't each smuggle in pet priorities.

**Format:** [9 Whys](https://www.liberatingstructures.com/nine-whys)

**Board / frame (ASCII):**
```
┌─────────────────────────────────────┐
│  Start: "Why prioritize now?"       │
│  → Why? → Why? … (up to 9)            │
│  PURPOSE STATEMENT (draft):           │
│  "We exist to __________ so that ___" │
└─────────────────────────────────────┘
```

**Facilitator instruction:** Run in groups of 5 (3 room tables + online breakout). Each group chains whys from a shared starting challenge. Merge to one purpose statement via wordsmith pair (not open debate). Purpose must not assume new budget.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 5 min | Frame starting challenge from NOW WHAT column |
| 2 | 25 min | Small groups: 9 Whys on board template |
| 3 | 15 min | Gallery walk (digital); dot top purpose phrases |
| 4 | 15 min | Facilitator + volunteer wordsmith; read draft purpose |

**Block output:** One purpose statement on board header (used all Day 2).

### Block: Hold tensions (14:00–15:00, Day 1)

**Why:** Name opposing truths (growth vs flat budget, central vs local, speed vs quality) so they don't explode during voting.

**Format:** [Wicked Questions](https://www.liberatingstructures.com/wicked-questions)

**Board / frame (ASCII):**
```
┌──────────────────────────────────────────────┐
│  WICKED QUESTION template:                   │
│  "How can we ___ AND ___ at the same time?"  │
├──────────────────────────────────────────────┤
│  WQ1: growth without new budget              │
│  WQ2: [group-generated]                      │
│  WQ3: [group-generated]                      │
└──────────────────────────────────────────────┘
```

**Facilitator instruction:** Seed WQ1 from constraint charter. Groups craft 2 more from Hopes/Fears. No resolving today — hold paradox. Redirect "we need more money" to "what would we stop to fund this internally?"

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 10 min | Explain wicked questions; seed budget WQ |
| 2 | 25 min | Triads (mixed): draft 2 WQs each → board |
| 3 | 15 min | Dot vote top 3 WQs to keep visible Day 2 |
| 4 | 10 min | Read WQs aloud; acknowledge tension without fixing |

**Block output:** Three wicked questions pinned; linked to World Cafe rounds.

### Block: Explore themes (15:15–16:30, Day 1)

**Why:** Broad, equal exploration across silos before convergence; remote voices get structured airtime.

**Format:** [World Cafe](https://theworldcafe.com/key-concepts-resources/world-cafe-method/)

**Board / frame (ASCII):**
```
┌─────────┬─────────┬─────────┐
│ Table 1 │ Table 2 │ Table 3 │  (+ Online Table 4)
│  Q: ___  │  Q: ___  │  Q: ___  │
├─────────┴─────────┴─────────┤
│  Round 1 │ R2 │ R3 → harvest │
│  Host stays; others rotate   │
└──────────────────────────────┘
```

**Facilitator instruction:** Four tables: three in room, one fully online (always-on video wall). Host stays; rotate every 20 min. Café prompt: "What strategic bets would advance our purpose within current resources?" Capture on table templates; hosts summarize to plenary (2 min each). Online host is an online advocate, not a note-taker only.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 10 min | Assign hosts; explain rotation + online table |
| 2 | 20 min | Round 1 |
| 3 | 20 min | Round 2 (rotate) |
| 4 | 20 min | Round 3 (rotate) |
| 5 | 15 min | Host summaries → sticky harvest to backlog wall |

**Block output:** 40–60 raw strategic bet stickies; table synthesis notes.

### Block: Narrow to five (11:45–12:30)

**Why:** Transparent, defensible narrowing to exactly five priorities under constraint.

**Format:** [Dot Vote](https://designsprintkit.withgoogle.com/methodology/phase4-decide/dot-vote) + [ToP Collaborative Priority Setting](https://www.top-network.org/set-priorities-collaboratively)

**Board / frame (ASCII):**
```
┌─────────────────────────────────────┐
│  Themes → Dot vote (5 dots/person)  │
│  → Top 8 → discuss → final Top 5    │
│  MUST-HAVE │ SHOULD │ COULD │ DROP  │
└─────────────────────────────────────┘
```

**Facilitator instruction:** Voting on board only (remote = dots on Miro, not proxies). After dot vote, use ToP priority matrix: Must/Should/Could/Drop for top 8. Facilitator proposes five from Must column; group refines — no new items. Explicit DROP list is as important as top 5.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 10 min | Dot vote on theme clusters |
| 2 | 15 min | Identify top 8; sort into Must/Should/Could/Drop |
| 3 | 20 min | Facilitated negotiation to exactly 5 Must-haves |

**Block output:** Top 5 priority cards + visible deprioritized list (min 5 items).

### Block: Stress-test (13:30–14:30)

**Why:** Expose failure modes before owners commit; reduce performative agreement.

**Format:** [Premortem](https://www.atlassian.com/team-playbook/plays/pre-mortem) + [The Worst We Could Do](https://retromat.org/en/?id=69)

**Board / frame (ASCII):**
```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ Priority │ Fail mode│ Worst    │ Early    │ Mitigation│
│    1     │          │ we could │ warning  │ (15%)    │
│   ...    │          │ do       │ signal   │          │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

**Facilitator instruction:** Per priority: 5 min silent "assume it failed — why?" then worst-we-could-do behaviors to avoid. Mitigations must not default to "get budget."

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 5 min | Premortem instructions |
| 2 | 40 min | Five rotations (8 min each priority) |
| 3 | 15 min | Cross-cut: top 3 systemic risks on board |

**Block output:** Risk row per priority; mitigation stickies.

### Block: Scope within control (14:30–15:15)

**Why:** Separate what the group can commit to without budget from what requires escalation — directly addresses political sensitivity.

**Format:** [Circles & Soup / Circle of Influence](https://retromat.org/en/?id=29)

**Board / frame (ASCII):**
```
        ┌─────────────┐
        │  CONTROL    │  ← 15% actions, owners here
        │  (circle)   │
        ├─────────────┤
        │  INFLUENCE  │  ← needs alignment, no budget promise
        ├─────────────┤
        │  CONCERN    │  ← soup: parking lot / escalate
        │  (soup)     │
        └─────────────┘
```

**Facilitator instruction:** Each priority: place proposed actions in circles. Anything in Concern tagged `#escalate` goes to sponsor after session — not smuggled into Q commitments. Say aloud: "Soup is not failure; it's honest scoping."

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 5 min | Explain circles; demo one priority |
| 2 | 30 min | Table work: classify actions for all 5 |
| 3 | 10 min | Report: count of control vs soup items |

**Block output:** Five priorities with control-ring actions only marked "committed"; soup items in parking lot.

### Block: Lock commitments (15:30–16:00)

**Why:** Move from consensus-by-silence to explicit consent with room for objections.

**Format:** [Sociocracy consent decision-making](https://patterns.sociocracy30.org/consent-decision-making.html)

**Board / frame (ASCII):**
```
┌─────────────────────────────────────┐
│  PROPOSAL: "We adopt these 5       │
│  priorities for Q+1 with named       │
│  owners and no new budget claims."   │
│  Objections → integrate or amend     │
│  Consent: no paramount objections    │
└─────────────────────────────────────┘
```

**Facilitator instruction:** Read proposal once. Round for clarifying questions, then reactions, then objections (must be paramount/safety). Use [Resolve Objections](https://patterns.sociocracy30.org/resolve-objections.html) if needed — max 5 min per objection. Executives speak last in objection round.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 5 min | Read proposal + top 5 list |
| 2 | 10 min | Clarifying questions round |
| 3 | 10 min | Objections round; integrate amendments |
| 4 | 5 min | Confirm consent; record dissent (not block) if any |

**Block output:** Consented priority list; amendment log; dissent notes.

**Why:** Translate agreement into owned, measurable first steps within existing authority.

**Format:** [15% Solutions](https://www.liberatingstructures.com/15-percent-solutions) + [ToP Action Planning](https://www.top-network.org/create-plans-collaboratively) + [Open Items List](https://retromat.org/en/?id=24)

```
├────────┼────────┼──────────────┼──────────┼──────────┤

│  ...   │        │              │          │          │
└────────┴────────┴──────────────┴──────────┴──────────┘
```

**Facilitator instruction:** Each priority: volunteer owner (or sponsor assigns if no volunteer — pause for side chat). 15% solution = action completable in 2 weeks without new budget. Success signal = observable by quarter end. Read back all five rows; thumbs consent.

**Timed flow:**

| Step | Time | Facilitator action |
| --- | --- | --- |
| 1 | 15 min | Fill action table live (owner speaks first) |
| 2 | 10 min | ToP action planning: resources already available? gaps to soup? |
| 3 | 5 min | Open Items List: parking lot owners + dates; closing appreciation |

**Block output:** Completed action table; open items with owners; verbal commitments on camera.

## Preparation

**Space / tools:**
- Room: cabaret seating (tables of 5–6), four World Cafe stations, wall/projector for digital board mirror
- Hybrid AV: ceiling mic, 2 room cameras, always-on gallery view for online table, chat monitored
- Digital board: Miro (primary source of truth) — zones: Frame, Hopes/Fears, WSW, Purpose, WQ, Cafe tables, Themes, Impact maps, Covers, Votes, Top 5, Risks, Circles, Actions, Parking lot
- Materials: timer visible to all, printed constraint charter at each table, name tents with role/team
- Pre-build board templates 48h ahead; test remote dot-voting and breakouts

**Pre-read / pre-work (send 5 business days before):**
- 2-page context brief: last quarter results, current budget reality (explicitly flat), known exec constraints
- Ask each participant to submit one "strategic bet" sticky text via form (seed Cafe backlog)
- Optional: [Agreement and Certainty](https://www.liberatingstructures.com/agreement-and-certainty) self-reflection — "What kind of decision is this for you?"
- Sponsors pre-briefed: no budget promises from the room; escalation path for soup items documented

**Facilitator roles:**
- **Lead facilitator:** arc, time, consent process, executive dynamics
- **Co-facilitator (room):** table coaching, parking lot, energy
- **Online advocate (mandatory):** remote parity, chat/hands, online World Cafe host, reads room aloud
- **Scribe:** live board hygiene, action table, export at end of each day
- **Executive sponsor:** opens Day 1 (5 min), receives soup list Day 2; does not steer votes

**Parking lot:**
- Digital column `#parking-lot`; verbal triggers: budget asks, HR/legal, interpersonal, out-of-quarter scope
- Revisit: end of each day (5 min), Circles & Soup block, final Open Items List
- Sponsor receives soup/escalate items within 24h — not bundled into the five priorities

## Hybrid / online parity

**Digital board:** Miro — single source of truth for all captures, votes, and final artifacts. Room uses projected board; no parallel flipcharts unless photographed into Miro within 5 minutes.

**Online group:** Seven participants always assigned to mixed breakouts (never "the online table alone" except as rotating World Cafe host station). Breakouts via Zoom/M Teams with Miro deep links. Online World Cafe host facilitates table 4 with co-fac check-ins each round.

**Parity rules:**
- If it is not on the board, it did not happen
- Online speakers first in all round-robins and objection rounds
- All voting via board dots — no show of hands in room
- Room comments near mic repeated by co-fac for online
- Gallery walks: 30 sec silent board read for remote before discussion
- No side conversations deciding priorities; use chat for clarifications only during votes

**Co-facilitation:**
- Online advocate monitors chat, raised hands, and connection issues; has authority to pause for parity
- Scribe reads new stickies aloud when created in room
- Lead debriefs with online advocate after Day 1 (15 min) to adjust Day 2 table assignments
